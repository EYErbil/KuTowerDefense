# Original game assessment and feature inventory

Audit baseline: `be87036f68d752d98d096f8f7c7f1a3ad6e082d6`, `Ege-redevelop`, initially clean. Audit performed 2026-10-19. Paths describe that historical revision after retirement.

## Structure and architecture

42 production Java classes, approximately 15,450 lines; six test sources with 77 test methods. JavaFX 17.0.2 Canvas plus controls/CSS; Maven and JUnit 5.9.2; no separate game engine. Entry flow: Main → MainMenuScreen → MapSelectionScreen → GameScreen → GameController.

GameScreen (~2,136 lines), GameController (~1,177), editor canvas (~953), editor screen (~880), Enemy (~792) and save service (~754) combine many responsibilities. Entities hold rendering objects. UI, spawning, combat, economy, input and persistence are tightly coupled.

`pom.xml` declares Java 11 in properties but compiler source/target 14; README's Java 11+/“run pom.xml” instructions are insufficient. Plugins: compiler 3.8.1, Surefire 3.0.0-M9, javafx-maven-plugin 0.0.8. Dependencies: JavaFX controls/fxml/media and JUnit. No wrapper, CI or release packaging.

There are only three playable tower classes and two enemy classes. Barracks/prebuilt-tower tiles are decoration. Five authored WaveConfig definitions do not drive actual spawning. No roguelike mode, branching tree, generalized synergy, boss or flying enemy exists.

## Rendering, movement and combat

AnimationTimer draws Canvas layers. Range scans and path progress select targets. Enemies follow path segments generated by grid BFS with castle-specific endpoint handling. Knight cooperation and splash scan enemy lists. Projectile proximity is checked before moving toward its target with frame delta.

Good work: atlas slicing/caching, progress targeting, placement feedback, transformed world interaction and editor organization. Retain the ideas without copying the coupling.

O(towers×enemies) range scans, potentially O(enemies²) cooperation, per-frame streams/copies/path work/logging are profiling concerns, not measured FPS findings. No independent simulation, spatial partition, replay, reliable complete saves or benchmark exists.

## Obsolete and missing

Unused/duplicated: controller/GamePlayScreen, model/GameSettings (active implementation is util/GameSettings), Path/PathPoint, largely unused WaveConfig. Retire assignment-specific tests/contracts rather than treating them as product requirements.

Missing systems include validated content, deterministic simulation, interaction engine, meaningful specialization, bosses, relics, run modifiers, analytics, accessibility, CI and reproducible release packaging. The roadmap prioritizes them rather than implementing all at once.

## Baseline verification

Default Java was 8; Maven was absent from PATH. JDK 23.0.1 and cached Maven 3.9.7 were available:

```powershell
$env:JAVA_HOME = 'C:\Users\USER\.jdks\openjdk-23.0.1'
$maven = 'C:\Users\USER\.m2\wrapper\dists\apache-maven-3.9.7-bin\3k9n615lchs6mp84v355m633uo\apache-maven-3.9.7\bin\mvn.cmd'
& $maven -o -B '-Dmaven.repo.local=C:\Users\USER\.m2\repository' '-Djavafx.platform=win' test
```

42 production classes compiled. Test compilation failed at five obsolete two-argument findPathBFS calls; implementation takes four arguments. All 30 map tests remained unexecuted.

Five other test sources were compiled separately against cached JavaFX/JUnit jars, then:

```powershell
& $maven -o -B '-Dmaven.repo.local=C:\Users\USER\.m2\repository' '-Djavafx.platform=win' '-Dtest=ArcherTowerTest,ArtilleryTowerTest,MageTowerTest,TowerTest,EgeTest' surefire:test
```

47 tests passed, zero failures/errors/skips. The normal full suite did not pass. Targeted JavaFX probes constructed the menu, rendered both saves and reproduced the defects above. No full manual playthrough or performance benchmark is claimed. Ignored target/audit-*.png and Surefire reports retain local evidence.
